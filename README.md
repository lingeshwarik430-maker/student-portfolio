
# Student Portfolio Website

## About the Project
A personal portfolio website developed using Python Flask, HTML and CSS to showcase a student's skills, projects, achievements and learning activities.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Git
- GitHub

## Features
- Personal Profile
- Technical Skills
- Academic Projects
- Achievements
- Learning Activities

## Project Structure
student-portfolio/
- app.py
- requirements.txt
- templates/index.html
- README.md

## Installation

1. Clone the repository:
   git clone https://github.com/lingeshwarik430-maker/student-portfolio.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   python app.py

4. Open in browser:
   http://127.0.0.1:5000
